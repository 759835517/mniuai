## 二、执行步骤（按顺序）

### 第1 步：安装 pnpm（如未安装）

```bash
npm install -g pnpm@9.15.0
```

### 第 2 步：迁移现有 front-end 代码到 engineer-app

```bash
cd D:/IdeaProjects/mniuai
bash scripts/migrate-to-monorepo.sh
```

迁移完成后，`apps/engineer-app/src/` 内容：
```
src/
├── app/# 所有页面路由（原样保留）
├── components/    # 业务组件
├── lib/           # api / stores / types / utils（原样保留）
│   └── apiClient.ts  # 新增，替换原lib/utils/apiClient
└── middleware.ts
```

### 第 3 步：将共享 UI 组件迁移到 packages/ui

把 `apps/engineer-app/src/components/ui/` 里所有 shadcn 组件**复制**到 `packages/ui/src/components/ui/`，然后在各端按需 import：

```bash
cp -r apps/engineer-app/src/components/ui packages/ui/src/components/
```

三端均可直接使用：
```typescript
import { Button, Card, Input } from "@mniuai/ui";
```

### 第 4 步：更新 engineer-app 中的 import 路径

原来的 `apiClient.ts` import 需要更新：

```bash
# 批量替换 engineer-app 内的 import 路径
cd apps/engineer-app
# 原路径 -> 新路径
# @/lib/utils/apiClient -> @/lib/apiClient
find src -name "*.ts" -o -name "*.tsx" | \
  xargs sed -i 's|@/lib/utils/apiClient|@/lib/apiClient|g'
```

### 第 5 步：安装所有依赖

```bash
cd D:/IdeaProjects/mniuai
pnpm install
```

pnpm 会自动解析 `workspace:*` 依赖，将 `@mniuai/ui` 等链接到各app。

### 第 6 步：验证启动

```bash
# 只启动程序员端（开发最常用）
pnpm dev:engineer

# 全部同时启动
pnpm dev
```

访问验证：
- 程序员端：`http://localhost:3000`
- 少儿端：`http://localhost:3001`（页面为空，待开发）
- 运营端：`http://localhost:3002`（页面为空，待开发）

## 三、后端 API 路由对应关系

| 前端应用 | 环境变量 `NEXT_PUBLIC_API_URL` | 后端 Controller路径 |
|---|---|---|
| engineer-app | `/api/v1/engineer` | `@RequestMapping("/api/v1/engineer/...")` |
| kids-app | `/api/v1/kids` | `@RequestMapping("/api/v1/kids/...")` |
| admin-app | `/api/v1/admin` | `@RequestMapping("/api/v1/admin/...")` |
| 三端共享 | `/api/v1/common` | `@RequestMapping("/api/v1/common/...")` |

后端需新建对应前缀的 Controller（原有 Controller 路径不动，新模块按新前缀建）。
