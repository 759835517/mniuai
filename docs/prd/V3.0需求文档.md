## 四、新增端设计

### 4.1 大学生就业保障端— `campus.mniuai.com`

**核心定位**：零基础 → AI 能力 → 第一份工作（对赌：毕业6个月内就业）

**学习路径**：
```
阶段1（4周）：AI工具快速上手
  → ChatGPT/Kimi 提效 / AI写作 / AI设计基础

阶段2（6周）：一个方向深入
  → 选择：AI产品助理 / AI数据分析 / AI运营专员/ AI测试工程师

阶段3（4周）：求职冲刺
  → 简历AI优化 / 模拟面试 / 作品集打磨 / 内推资源对接

阶段4：持续陪跑
  → 就业后30天跟踪 / 入职适应指导
```

**对赌条件**：
- 完成全程学习（有效学时 ≥ 80%）
- 完成至少 3 个作品集项目
- 参与至少 10 次模拟面试
- 毕业/离职后 180 天内未就业 → 全额退款

---

### 4.2 教师/教育从业者端 — `edu.mniuai.com`

**核心定位**：AI 助力教师减负增效，不是替代老师，是让老师多出时间陪学生

**核心功能模块**：

| 功能 | 说明 | AI能力 |
|---|---|---|
| **AI备课助手** | 输入课题+年级，生成教案、PPT大纲、板书设计 | Qwen生成+模板化 |
| **试卷题库生成** | 按知识点、难度、题型自动出题 | RAG+题库检索 |
| **学生简讯生成** | 输入班级活动，生成学校推文/家长通知 | 图文生成 |
| **作业批改辅助** | 上传作业图片，AI给出批改建议 | 视觉+语言模型 |
| **课件AI美化** | 文字内容一键生成PPT | 结构化生成 |
| **家校沟通模板** | 各种通知、请假回复、家长会邀请模板 | Prompt模板库 |

**对赌条件**：
- 连续使用30天，AI工具使用频次 ≥ 50次
- 自评备课时间减少未达50% → 退款

---

### 4.3 职场AI赋能端 — `pro.mniuai.com`

**覆盖人群**（同一个端，按"我是谁"分模块）：

#### 模块A：自媒体/内容运营
- 爆款标题生成器（输入主题→10个标题选）
- 视频脚本 AI生成（抖音/小红书/B站格式）
- 封面文案 + 配图提示词生成
- 热点追踪 + 选题建议（接入热搜API）
- 数据复盘 AI 分析（上传播放量/点赞数据）

#### 模块B：公众号运营
- 公众号文章 AI 写作（输入关键词→完整文章）
- 排版优化建议（H5风格选择）
- 系列内容规划（月计划自动生成）
- 互动评论 AI 回复模板
- 历史文章数据分析+改进建议

#### 模块C：门店小老板AI获客
- 朋友圈文案生成（不同行业模板：餐饮/美妆/教育）
- 活动策划 AI 助手（节日/节气营销方案）
- 客户回复话术库（售前/售后/复购催单）
- 本地化推广文案（周边社区风格）
- 小程序/视频号内容生成

#### 模块D：学校/机构简讯生成
- 学校活动推文生成（运动会/毕业典礼/家长会）
- 正式公文格式化（通知/决定/报告）
- 家校沟通周报自动生成
- 荣誉通报模板
- 招生简章 AI 撰写

**对赌条件**：按模块定义
- 自媒体：3个月内粉丝增长 < 500 或 GMV < X → 退款
- 小老板：1个月内使用工具次数 ≥ 30次仍感觉无效果 → 退款

## 十、开发优先级建议

###阶段一（0-3个月）：打通已有 + 官网上线
- 程序员端功能跑通（当前主线）
- 官网 `mniuai.com` 上线（人群分流+ 课程广场 + 对赌说明）
- admin-app CMS 后台上线（支持多端内容发布）

### 阶段二（3-6个月）：扩展两端
- 教师端 `edu.mniuai.com`（工具型，开发周期短，付费路径清晰）
- 大学生端 `campus.mniuai.com`（复用程序员端大部分代码）

### 阶段三（6-12个月）：职场赋能 + 规模化
- 职场赋能端 `pro.mniuai.com`（内容生成工具 + 课程）
- 少儿端精品化
- 企业端 `biz.mniuai.com`

---

**教师端和大学生端是下一阶段最值得优先做的两个端**，原因：
- 教师端：工具型产品，AI调用逻辑简单，但付费意愿高，口碑传播快（一个老师带一个学校）
- 大学生端：可复用程序员端80%代码，对赌承诺强，年轻用户付费习惯好
