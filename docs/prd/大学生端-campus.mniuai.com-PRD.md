## 一、背景与目标

### 1.1 背景

应届大学生就业市场持续内卷：计算机相关专业毕业生年均超 100 万，但超过 60% 缺乏可投递的工程项目，面试通过率极低。传统培训班课时长（6个月）、价格高（2~3万），学员完课率仅 40%，就业结果难以保障。

萌牛AI大学生端（campus.mniuai.com）定位为**AI驱动的零基础就业保障平台**，通过视频课程 + AI编程助手 + 真实项目实战 + AI面试官 + 就业对赌，帮助大学生在3~6个月内从零成长为可就业工程师。

### 1.2 核心差异化

| 差异点 | 传统培训 | campus.mniuai.com |
|---|---|---|
| 学习方式 | 视频+课堂 | 视频+AI实时辅助+实战项目 |
| 项目质量 | 统一项目Demo | 个性化项目作品集 |
| 面试准备 | 刷题+模拟面试 | AI面试官24h陪练 |
| 就业保障 | 承诺就业（难核查）| 对赌协议+数据可查 |
| 价格 | ¥15,000~30,000 | ¥3,999/期（对赌保障版） |

### 1.3 目标

1. 就业结果：完成全部学习路径的学员，6个月内就业率 ≥ 70%
2. 学习完成率：核心路径完课率 ≥ 50%
3. 用户增长：3个月内注册大学生 ≥ 10,000 人
4. 付费转化：免费→付费转化率 ≥ 15%
5. 对赌退款率：≤ 8%（即就业成功率高）
6. NPS：≥ 55，学员推荐率 ≥ 45%

### 1.4 成功指标

| 指标 | 目标值 | 测量方式 |
|---|---|---|
| 注册大学生数 | 3月内 ≥ 10,000 | 注册数据 |
| 核心路径完课率 | ≥ 50% | 课程完成事件 |
| 月活学员 | ≥ 3,000 | 登录+学习行为 |
| 付费转化率 | ≥ 15% | 订单数据 |
| 6个月就业率 | ≥ 70% | 就业问卷+Offer截图 |
| 对赌退款率 | ≤ 8% | 退款申请记录 |
| AI面试通过率提升 | 首次面试通过率+30% | A/B用户对比 |

  - 高频LeetCode 100题（分类练习）

| 功能模块 | 优先级 | 核心价值 | 估计工作量 |
|---|---|---|---|

| 对赌就业机制 | P0 | 转化核心，信任建立 | 5d |

### 4.2 视频课程系统（P0）

**功能描述**：分章节、分节视频学习，支持进度记录、笔记、倍速播放。

**核心规格**：
- 视频格式：HLS 流，支持 0.75x / 1x / 1.25x / 1.5x / 2x 倍速
- 进度自动保存：每 10 秒上报一次进度，断点续播
- 课内练习：视频中插入编程小题（Inline Exercise），暂停视频要求完成
- 字幕：中文字幕，支持关键词搜索跳转
- 课后作业：每章节末有提交入口，提交后 AI 自动批改

**业务规则**：
- 付费课程仅付费用户解锁，试看前 2 节
- 每节课完成后更新学习进度，触发成就勋章
- 视频完成率 < 60% 时，AI助教主动推送"继续学习"提醒
- 课程版本更新时，已购用户自动解锁新内容

### 4.3 编程练习环境（P0）

**功能描述**：浏览器内在线代码编辑器，支持运行、调试、AI提示。

**技术规格**：
- 编辑器：Monaco Editor（VS Code同款）
- 运行环境：沙盒执行（Docker + 资源限制）
- 支持语言：JavaScript, Python, Java, SQL
- 测试用例：每道题预置 5~10 个测试用例，含边界场景
- 执行限制：30 秒超时，256MB 内存

**AI提示机制（逐级）**：
- Level 1：提示涉及的知识点类型
- Level 2：提示需要检查的具体代码位置
- Level 3：给出解题思路（不给代码）
- Level 4：给出伪代码或部分实现
- Level 5：完整参考实现+解释（需消耗提示配额）

**评分规则**：
- 通过全部测试：100分
- 部分通过：按通过数/总数比例
- 使用提示：扣除对应分数（Level5扣40分）
- 代码质量分（可选）：AI评估命名、结构、时间复杂度

### 4.4 AI学习助教（P0）

**功能描述**：嵌入学习流程的对话式AI，帮助理解概念、解决报错、检查代码。

**能力范围**：
- 解释视频/文档中的技术概念（引用具体章节）
- 分析编译/运行报错，给出修复建议
- 代码审查：指出安全、性能、可读性问题
- 逐步引导（不直接给答案）
- 推荐下一步学习内容

**禁止行为**：
- 直接给出作业题和考试题的完整答案
- 编造不存在的 API 或库
- 帮助绕过练习环境的安全限制

**系统架构**：
- 上下文：当前课程章节、学员历史错误、当前代码内容
- 知识库：课程文档 + 官方文档摘要（RAG）
- 模型：Qwen-Max（质量优先）
- 成本控制：每次对话 ≤ 2000 tokens 输入，长对话压缩历史

### 4.5 对赌就业机制（P0）

**承诺**：完成全部学习要求，6个月内未找到相关工作，全额退款。

**退款条件（需同时满足）**：

| 门槛项 | 标准 |
|---|---|
| 课程完成率 | 核心路径视频完成率 ≥ 80% |
| 编程练习 | 完成 ≥ 200 道练习题，通过率 ≥ 60% |
| 实战项目 | 提交并通过 ≥ 2 个项目（AI+人工审核）|
| AI面试 | 完成 ≥ 10 轮AI模拟面试 |
| 简历 | 使用平台生成简历并主动投递 ≥ 50 家 |
| 时限 | 付款后 270 天（9个月）内申请 |
| 活跃度 | 每周有学习记录，无连续断更 ≥ 4 周 |

**就业认定**：
- 成功：提供 Offer 截图（含薪资）或入职证明
- 相关岗位：软件开发、测试、数据分析、产品等技术相关
- 薪资不做下限要求（防止因薪资不理想拒绝Offer后索赔）

**退款流程**：
```
申请退款 → 系统核查完成度 → 满足→ 审核组人工复核（5工作日）
→ 确认未就业（电话核实） → 退款到账
→ 不满足 → 显示缺口 + 建议继续完成
```

**风险控制**：
- 投递记录：平台内推荐投递可追踪，外部投递需上传截图
- 虚假投递防范：邮件记录 + 随机抽查 2~3 份投递
- 申请期限：付款后 9 个月（太早申请可能还未满学习条件）

### 4.6 AI面试官（P1）

**功能描述**：模拟真实技术面试，AI扮演面试官，根据学员回答动态追问。

**面试类型**：
- 算法面试：LeetCode题，要求口述思路 + 现场编码
- 技术概念面试：语言特性、框架原理、数据库、网络等
- 项目面试：深挖简历项目，考察理解深度
- 系统设计面试：设计一个规模化系统（高级路径）
- HR面试：薪资期望、职业规划、行为问题

**面试流程**：
```
选择面试类型 → 设置难度（初级/中级）
→ AI面试官自我介绍 → 开始提问（随机+自适应）
→ 学员语音/文字回答 → AI追问
→ 30~45分钟后结束 → AI评分报告（维度：正确性/表达/深度）
→ 薄弱点分析 → 推荐复习资料
```

**评分维度**：
- 知识正确性（40%）
- 回答完整度（25%）
- 表达清晰度（20%）
- 应变能力（15%）

**学员可见报告**：
- 总评分 + 各维度分数
- 关键失分点（具体问题+标准答案）
- 与同等级用户对比（分位数）
- 推荐重点复习清单

### 4.7 项目作品集（P1）

**功能描述**：学员完成实战项目后，平台自动生成专业项目展示页面。

**项目卡片内容**：
- 项目名称 + 技术栈徽章
- 项目描述（AI辅助润色）
- 核心功能截图
- GitHub 仓库链接
- 部署链接（Vercel/Railway）
- 技术挑战与解决方案

**作品集主页**：
- 个人作品集页面（campus.mniuai.com/@username）
- 支持自定义域名
- 响应式设计，可直接发给面试官
- 内嵌项目完成认证徽章（平台背书）

### 4.8 简历生成器（P1）

**功能描述**：基于学员填写的信息 + 平台学习记录，AI生成可投递的工程师简历。

**内容来源**：
- 基础信息（学员填写）
- 技能栈（来自学习路径完成记录）
- 项目经历（来自作品集）
- 教育经历（学员填写）
- AI帮助优化描述语言（STAR原则、量化成果）

**导出格式**：
- PDF（一键下载）
- Word（可进一步修改）
- 在线简历链接（可直接分享）

### 6.3 AI模型配置

- AI助教：Qwen-Max（知识问答，质量优先）
- AI面试官：Qwen-Max（对话连贯性，动态追问）
- 代码评测辅助：Qwen-Coder（代码专项）
- 简历生成：Qwen-Turbo（快速生成，速度优先）
- 成本估算：AI助教 ≈ 0.3元/次，面试 ≈ 2元/轮

### 6.4 沙盒代码执行

- 执行引擎：Judge0（开源）或 自建 Docker Runner
- 支持语言：JavaScript (Node 20), Python 3.11, Java 21, SQL (SQLite)
- 限制：30秒超时，256MB 内存，禁止网络请求，禁止文件系统写入
- 测试结果格式：{ passed, total, cases: [{input, expected, actual, status}] }
