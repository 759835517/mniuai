## 一、背景与目标

### 1.1 背景

mniuai（萌牛AI）定位为**全社会 AI 赋能综合平台**，服务人群涵盖程序员、少儿、大学生、教师、自媒体运营者、门店小老板等多个社会群体。各垂直端（app/kids/campus/edu/pro）独立部署，需要一个统一的官方网站作为品牌中枢和流量分发入口。

### 1.2 目标

1. 建立品牌认知：让访客在 30 秒内理解"萌牛AI是什么、能帮我做什么"
2. 精准分流：根据用户身份引导进入对应垂直端，减少决策摩擦
3. 提升付费转化：对赌协议说明页降低购买顾虑，课程广场促进冲动购课
4. SEO 引流：博客/案例内容获取自然搜索流量
5. 信任背书：成功案例、合作机构、媒体报道建立公信力

### 1.3 成功指标

| 指标 | 目标值 |
|---|---|
| 访客→注册转化率 | ≥ 8% |
| 官网→各端跳转率 | ≥ 35% |
| 对赌协议页面到付费转化 | ≥ 15% |
| 博客页面自然搜索流量占比 | 6个月内 ≥ 30% |
| 平均停留时长 | ≥ 90 秒 |
| 移动端跳出率 | ≤ 55% |

## 五、人群专属落地页（/for/xxx）

每个落地页结构统一，内容差异化。以下以**程序员落地页** `/for/engineer` 为示例，其余人群参照执行。

③ 学习路径时间轴
④ 核心功能/工具展示
⑤ 对赌协议详细说明

⑦ 常见问题 FAQ
⑧ 最终CTA（注册/立即购买）

### 5.2 程序员落地页（/for/engineer）

**Hero 标题**：
> "90 天，从传统后端到 AI 工程师，找不到工作全额退款"

**痛点 3 条**：
- 自学 AI 方向不明，看了很多教程还是不知道从哪下手
- 面试卡在算法题和系统设计，投了 50 份简历石沉大海
- 公司要求 AI 能力，但不知道如何把 AI 用在真实项目中

**核心能力路径（时间轴）**：

| 周次 | 主题 | 目标 |
|---|---|---|
| 第 1-2 周 | AI 编程基础 | 用 AI 完成第一个真实需求 |
| 第 3-4 周 | AI 实战项目 | 独立完成 RAG/Agent 应用 |
| 第 5-8 周 | 面试强化 | 算法/系统设计/行为面试通关 |
| 第 9-12 周 | 求职冲刺 | 简历优化 + 内推 + offer谈判 |

**对赌说明**：
- 有效学习时长 ≥ 80%
- 完成 ≥ 10 次模拟面试
- 结业后 90 天无 offer → 全额退款

**CTA 按钮**：`立即报名，0 风险开始` → 跳转 app.mniuai.com/register

| 首页、关于、对赌 | SSG（静态生成） | SEO + 性能 |
| 课程广场、落地页 | ISR（增量静态再生，revalidate=3600） | 内容更新不频繁 |
| 课程详情页 | ISR（revalidate=1800） | 价格/人数变化 |
| 博客文章 | ISR（revalidate=86400） | 每日更新 |
| 联系表单提交 | Client-side API call | 动态交互 |

## 十三、数据埋点设计

### 13.1 核心事件

| 事件名 | 触发时机 | 关键属性 |
|---|---|---|
| `page_view` | 任意页面加载 | page_path, referrer, utm_source |
| `hero_persona_click` | 点击首页人群卡片 | persona（engineer/kids/campus/teacher/creator/business） |
| `cta_click` | 点击任意 CTA 按钮 | cta_text, page_path, persona |
| `course_card_click` | 点击课程卡片 | course_id, course_name, persona, position |
| `guarantee_section_view` | 对赌区域进入视口 | page_path |
| `guarantee_page_visit` | 访问 /guarantee | referrer_page |
| `landing_page_visit` | 访问 /for/xxx | persona |
| `register_click` | 点击注册/立即报名按钮 | persona, course_id, page_path |
| `blog_article_read` | 博客文章阅读完成（滚动>85%） | article_slug, category |
| `contact_form_submit` | 提交联系表单 | form_type |

### 13.2 转化漏斗

```
page_view → hero_persona_click → cta_click → register_click → 完成注册
```
