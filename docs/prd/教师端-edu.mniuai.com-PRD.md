## 一、背景与目标

### 1.1 背景

中小学和高校教师普遍面临备课时间长、出题繁琐、批改作业耗时等问题。AI 技术的发展为教师减负提供了新可能，但市面上缺乏专门针对教师场景设计的 AI 工具平台。

萌牛AI 教师端（edu.mniuai.com）定位为**教师专属 AI 效率工具平台**，覆盖备课、出题、批改、课件制作全流程，帮助教师每周节省 10+ 小时。

### 1.2 目标

1. 提效目标：教师使用 AI 工具后，备课+出题+批改时间节省 50% 以上
2. 留存目标：30 日留存率 ≥ 60%，工具使用频次 ≥ 周均 5 次
3. 付费转化：免费试用→付费转化率 ≥ 20%
4. 对赌保障：使用 50 次后自评无效→全额退款
5. 口碑传播：NPS ≥ 50，教师推荐率 ≥ 40%

### 1.3 成功指标

| 指标 | 目标值 | 测量方式 |
|---|---|---|
| 注册教师数 | 3 个月内 ≥ 5000 人 | 注册数据 |
| 工具使用频次 | 周均 ≥ 5 次 | 埋点统计 |
| 30 日留存率 | ≥ 60% | Cohort 分析 |
| 付费转化率 | ≥ 20% | 订阅数据 |
| 平均节省时间 | ≥ 10 小时/周 | 用户自评问卷 |
| 退款率 | ≤ 3% | 退款记录 |

## 三、核心功能设计

### 3.1 功能优先级总览

| 功能模块 | 优先级 | 核心价值 | 估计工作量 |
|---|---|---|---|
| AI 备课助手 | P0 | 最高频使用，直接体现价值 | 5d |
| AI 出题机 | P0 | 教师核心痛点，强对赌支撑 | 5d |
| 模板库 | P0 | 降低使用门槛，提升首次成功率 | 3d |
| 用户中心+使用记录 | P0 | 支撑对赌数据采集 | 3d |
| AI 批改助手 | P1 | 高价值但复杂度高 | 8d |
| AI PPT 生成 | P1 | 差异化竞争力 | 6d |
| 题库管理 | P1 | 提升复用价值 | 4d |
| 班级管理 | P2 | 扩展场景，后期迭代 | 5d |

### 3.2 AI 备课助手（P0）

**功能描述**：教师输入学科/年级/课题/课时目标，AI 生成完整教案框架及内容。

**输入参数**：
- 学科（语文/数学/英语/物理/化学/历史/政治/体育/其他）
- 年级（1年级 ~ 高三）
- 课题名称（必填）
- 课时时长（40/45/90 分钟）
- 教学目标（可选，AI 可自动推断）
- 教材版本（人教版/北师大版/苏教版等）

**输出结构**：
```
教案标题
学情分析
教学目标（知识、能力、情感）
教学重难点
教学方法
教学流程（导入→新授→练习→小结→作业）
板书设计
教学反思提示
```

**业务规则**：
- 生成时间 ≤ 15 秒（P99），超时降级为分段流式输出
- 教案可在线编辑，支持富文本（加粗/列表/表格）
- 支持导出为 Word (.docx) 和 PDF
- 保存到"我的教案库"，支持按学科/年级/时间检索
- 历史教案可二次编辑和再生成

**AI 行为边界**：
- 禁止生成包含政治敏感、宗教、暴力内容的教案
- 教材版本不确定时，生成通用版本并注明
- 知识点有争议时，提示"建议参考最新课程标准"
- 拒绝生成用于欺骗学校/教育部门的虚假教案

### 3.3 AI 出题机（P0）

**功能描述**：教师选择知识点/题型/难度，AI 自动生成试题，支持组卷成完整试卷。

**出题参数**：
- 学科 + 年级 + 知识点（多选，支持搜索）
- 题型：单选 / 多选 / 判断 / 填空 / 简答 / 计算 / 作文
- 难度：容易 / 中等 / 较难（可按比例混合）
- 数量：每次 1~50 题
- 是否附答案和解析

**组卷功能**：
- 从生成的题目中勾选，加入试卷
- 设置分值和总分
- 设置页面格式（单栏/双栏，A4）
- 导出为 Word 试卷（含答题卡格式）

**题目质量保障**：
- AI 生成后标注"AI生成，建议人工核查"
- 计算类题目给出计算过程
- 语文作文给出评分标准和参考提示
- 支持教师对题目点"有问题"，触发后台采集用于训练优化

**题库管理**：
- 生成的题目自动入"我的题库"
- 支持按学科/年级/知识点/难度检索
- 支持手动添加自定义题目
- 支持标注"常考题""错题"

### 3.4 AI 批改助手（P1）

**功能描述**：教师上传学生作业/试卷图片或文本，AI 初步批改并给出评分和批注。

**支持场景**：
- 主观题：作文、简答题、解答题批改
- 客观题：选择题自动比对（需教师预设答案）
- 整份试卷：OCR 识别+综合批改

**批改流程**：
```
教师上传 → OCR 识别学生答案 → AI 比对标准答案 → 给出分数 + 批注
→ 教师审阅（确认/修改） → 生成成绩单 → 可导出 Excel
```

**AI 批改规则**：
- 客观题：完全自动，准确率 ≥ 99%
- 简答题：AI 给出 0~100 参考分 + 要点覆盖分析，教师最终定分
- 作文：从内容/结构/语言/创意四个维度给出分数和具体批注
- 所有 AI 批改结果标注置信度，低置信度优先推送人工审阅

**数据安全**：
- 学生作业图片加密存储，保留 90 天后自动清除
- 禁止将学生信息用于模型训练（除非获得明确授权）

### 3.5 AI PPT / 课件生成（P1）

**功能描述**：教师输入课题，AI 生成结构化课件大纲，并渲染为可下载的 PPT 文件。

**输入**：课题名称 + 学科 + 年级 + 课时目标 + 风格偏好（简约/活泼/学术）

**输出**：
- 在线预览：分页展示每张幻灯片内容（标题+要点+配图建议）
- 导出 PPTX（使用 pptxgenjs 生成，可在 PowerPoint/WPS 直接编辑）
- 可选：插入图表（柱状图/折线图）、数学公式（LaTeX 渲染）

**模板库**：内置 10+ 种教学风格模板，支持选择后重新渲染

### 3.6 模板库（P0）

**核心价值**：降低首次使用门槛，教师直接选模板、填内容，10 分钟完成一节课备课。

**模板分类**：
- 教案模板：通用教案 / 公开课教案 / 微课教案
- 课件模板：启发式课件 / 习题讲解课件 / 项目式学习课件
- 出题模板：单元测验 / 期中 / 期末 / 随堂小测
- 通知模板：家长会通知 / 作业提醒 / 活动通知 / 请假通知

**管理规则**：
- 官方模板：产品团队维护，标注"官方精选"
- 用户模板：教师保存自己的作品为模板，可设置公开（贡献社区）或私有
- 热门模板：按使用次数排序，周更新 Top 10

## 五、对赌协议机制

### 5.1 退款触发条件

**条件**：工具使用总次数 ≥ 50 次，且用户自评效率无提升 → 申请全额退款。

### 5.2 学习门槛（需同时满足）

| 门槛项 | 标准 | 数据来源 |
|---|---|---|
| 工具使用次数 | ≥ 50 次（不含重复刷新） | 服务端 usage 记录 |
| 连续使用天数 | ≥ 30 天 | 按自然日统计 |
| 不同功能使用 | 至少用过 3 个工具模块 | 模块使用记录 |
| 有效使用时长 | 单次 ≥ 3 分钟的记录 ≥ 30 条 | 会话时长统计 |

### 5.3 "一次使用"的界定

以下操作计入 1 次有效使用：
- 完成一次 AI 备课（生成结果且停留 ≥ 3 分钟）
- 生成 ≥ 5 道题目（出题机）
- 完成一批作业批改（≥ 5 份）
- 生成一份 PPT（≥ 8 页）

以下**不计入**：
- 页面仅停留 < 30 秒
- 未生成结果就离开
- 同一内容重复生成（去重，间隔 < 5 分钟）

### 5.4 退款申请流程

```
用户申请退款
     ↓
系统自动核查：使用次数 + 使用天数 + 功能广度
     ↓
满足门槛 → 自评问卷（5题，了解真实情况）
     ↓
问卷结果 → 72 小时退款到账
不满足门槛 → 显示缺口详情 + 建议继续使用
     ↓
申诉通道：客服人工审核（3 个工作日）
```

### 5.5 申请截止时间

- 付款后 60 天内，累计达到门槛后可申请
- 超过 60 天视为认可效果，不再受理退款

### 6.3 AI 模型配置

- 主模型：Qwen-Max（备课/出题/批改，质量优先）
- 速度模型：Qwen-Turbo（快速生成大纲，延迟优先）
- OCR：阿里云OCR（作业批改图片识别）
- 成本控制：备课约 0.5-1 元/次，出题约 0.2-0.3 元/次

### 6.4 渲染策略

| 页面 | 策略 | 原因 |
|---|---|---|
| 首页、定价、对赌说明 | SSG | SEO + 性能 |
| 工具页 | CSR（"use client"） | 实时 AI 交互 |
| 我的教案库/题库 | SSR + ISR | 个人数据 + 快速加载 |
| 模板库 | ISR（revalidate=3600） | 内容更新不频繁 |

## 九、验收标准

### 9.1 功能验收

- [ ] AI 备课助手：输入课题 5 个字以上，15 秒内完成流式输出
- [ ] 教案支持 Word/PDF 导出，格式规范
- [ ] 出题机：10 题生成时间 ≤ 8 秒，题目不重复
- [ ] 组卷功能：分值设置正确，Word 导出含答题卡格式
- [ ] 批改助手：单张图片 OCR 时间 ≤ 5 秒
- [ ] PPT 导出：PPTX 文件可在 PowerPoint/WPS 正常打开
- [ ] 模板库：点击模板可预览全部内容，一键应用
- [ ] 使用统计：次数计算准确，对赌进度实时更新
- [ ] 对赌申请：系统自动核查结果与人工核查一致性 ≥ 95%

### 9.2 性能验收

| 指标 | 要求 |
|---|---|
| AI 生成首字节时延 | ≤ 2 秒 |
| 页面 LCP | ≤ 2.5 秒 |
| 文件导出等待时间 | ≤ 5 秒（Word/PPT ≤ 10 秒） |
| OCR 识别时间 | ≤ 5 秒/页 |
| 并发支持 | ≥ 200 并发 AI 请求不降级 |

### 9.3 安全验收

- [ ] 学生作业图片仅登录用户可访问，URL 带签名
- [ ] AI 输出内容过滤政治敏感/违法词汇
- [ ] 用户数据不用于第三方模型训练
- [ ] 对赌核查日志不可篡改

## 十一、风险与待确认项

| 风险 | 影响 | 缓解措施 |
|---|---|---|
| AI 生成教案质量不稳定 | 用户不信任，流失 | 建立人工审核的优质教案样本库；允许用户评分反馈 |
| OCR 识别率低（模糊图片）| 批改功能体验差 | 明确上传要求（清晰/光线充足）；低置信度自动转人工 |
| 课程标准版本差异大 | 生成内容不符合本地要求 | 支持多版本教材选择；生成后提示"以当地课标为准" |
| 对赌退款申请量超预期 | 资金压力 | 设置申请期限（60天）；前端引导改善使用方式 |
| 教师手机端使用需求强 | 桌面端体验不适配 | Phase 1 适配移动端响应式；Phase 2 考虑微信小程序 |

### 待确认项

- [ ] AI 模型选型：Qwen-Max 还是接入更多模型做路由？
- [ ] OCR 服务：自建还是用阿里云 OCR？
- [ ] 对赌门槛：50 次是否合理？需要用户访谈验证
- [ ] PPT 导出风格：是否需要与学校品牌定制？
- [ ] 是否支持微信登录（教师群体常用手机）？
- [ ] 学校团队版的管理后台范围？
