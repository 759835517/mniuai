## 一、背景与目标

### 1.1 背景

国内互联网行业进入存量竞争时代，工程师面临三大困境：
1. **技术升级焦虑**：AI工具（Cursor/Copilot）快速迭代，不会用AI编程的工程师效率落后
2. **面试难度升级**：大厂面试从算法题卷到系统设计、AI应用开发、工程实践
3. **薪资天花板**：初中级工程师薪资增长停滞，跳槽涨薪需要硬实力证明

传统技术培训（极客时间/拉勾教育）以视频课为主，缺乏实战和即时反馈。LeetCode 刷题只覆盖算法，不涉及工程能力。

萌牛AI程序员端（app.mniuai.com）定位为**AI驱动的工程师能力提升平台**，通过 AI编程实战 + 真实场景练习 + AI面试官陪练，帮助工程师在 3~6 个月内完成技能升级，实现跳槽涨薪或晋升目标。

### 1.2 核心差异化

| 差异点 | 传统课程平台 | LeetCode | app.mniuai.com |
|---|---|---|---|
| 学习方式 | 视频课 | 刷题 | AI实战+面试陪练 |
| 内容深度 | 概念讲解为主 | 纯算法 | 算法+工程+AI编程 |
| 实时反馈 | 无 | 测试用例通过 | AI即时指导+代码审查 |
| 面试准备 | 无 | 算法题 | 算法+系统设计+行为面试 |
| 效果保障 | 无 | 无 | 对赌涨薪/晋升 |
| 价格 | ¥199~999/年 | ¥159/年 | ¥599/月（对赌版¥2999/半年）|

### 1.3 目标

1. 技能提升：完成核心路径学员，AI编程效率提升 ≥ 40%，算法刷题效率提升 ≥ 50%
2. 面试通过率：使用AI面试官练习 ≥ 20 轮的学员，真实面试通过率 +35%
3. 用户增长：3个月内注册工程师 ≥ 20,000 人
4. 付费转化：免费→基础版 ≥ 20%，基础版→对赌版 ≥ 15%
5. 对赌达成：对赌版学员 6 个月内涨薪/晋升成功率 ≥ 75%
6. 留存率：30 日留存 ≥ 55%，周活跃练习用户 ≥ 8,000

### 3.2 AI编程实战（P0）

**功能描述**：提供真实开发场景的任务（Bug修复、功能开发、重构），在 AI 辅助下完成，类似 Cursor 的使用体验。

**实战任务类型**：
- **Bug 修复**：给定一个有 Bug 的代码库，要求定位并修复
- **功能开发**：根据需求文档，补全一个功能模块
- **代码重构**：优化一段低质量代码，提升可读性和性能
- **单元测试补充**：为已有代码编写测试用例
- **性能优化**：分析并优化慢查询/慢接口

**AI辅助方式**：
- 嵌入式 AI 对话窗口（类似 Cursor 的 Cmd+K）
- 代码补全建议（基于上下文）
- 错误诊断和修复建议
- 代码审查（安全、性能、可读性）
- 逐步提示（不直接给答案，引导思考）

**评分标准**：
- 功能正确性（40%）：通过测试用例
- 代码质量（30%）：AI 评估命名、结构、注释
- 性能（15%）：时间/空间复杂度
- 完成时间（15%）：越快分数越高（鼓励使用 AI）

**技术规格**：
- 编辑器：Monaco Editor（VS Code 内核）
- 代码执行：沙盒环境（Docker），支持 Node/Python/Java/Go
- AI模型：Qwen-Coder（代码专项），上下文包含整个代码库
- 版本控制：每次保存创建 Git commit，可回退

### 3.3 算法题库 + AI讲解（P0）

**功能描述**：LeetCode 风格的算法题库，但增加了 AI 逐级提示和视频讲解。

**题库规模**：
- 精选 500 题（覆盖高频面试题）
- 按难度分类：简单 150 / 中等 250 / 困难 100
- 按类型分类：数组/链表/树/图/动态规划/贪心/回溯等

**AI讲解机制**：
- **提示模式**（类似大学生端）：
  - Level 1：提示算法类型（如"双指针"）
  - Level 2：提示关键步骤（如"先排序"）
  - Level 3：给出伪代码框架
  - Level 4：完整题解 + 复杂度分析
- **视频讲解**：困难题提供5~10分钟视频（真人讲师或AI生成）
- **举一反三**：完成一道题后，AI推荐3道类似变种题

**刷题模式**：
- 随机模式：每日一题推送
- 分类刷题：按知识点突破
- 面试公司专项：字节/阿里/腾讯/美团真题集
- 模拟面试：限时45分钟，2~3道题

**进度跟踪**：
- 已刷题数 / 总题数
- 按难度和类型的完成分布（热力图）
- 薄弱知识点标记（AI分析）

### 3.4 AI面试官（P0）

**功能描述**：模拟真实技术面试，覆盖算法、系统设计、项目经历、行为面试。

**面试类型**：
1. **算法面试**：AI 出题，要求口述思路 + 现场编码，动态调整难度
2. **系统设计面试**：设计一个高并发系统（如短链接服务、秒杀系统）
3. **项目深挖**：基于简历项目，AI 追问技术细节和难点
4. **行为面试**：STAR 原则回答，AI 评估逻辑和表达
5. **综合模拟**：完整 1 小时面试流程（算法+系统设计+项目）

**面试流程**：
```
选择面试类型 + 公司（字节/阿里/腾讯等）
→ AI面试官自我介绍
→ 开始提问（随机从题库抽取 + 根据简历定制）
→ 学员作答（语音/文字 + 编码）
→ AI 追问（基于回答质量动态调整）
→ 45~60 分钟后结束
→ 生成面试报告（评分 + 薄弱点 + 改进建议）
```

**评分维度**：
- 算法正确性（35%）
- 代码质量（20%）
- 沟通表达（20%）
- 问题理解（15%）
- 时间管理（10%）

**面试报告**：
- 总评分 + 各维度雷达图
- 具体失分点（某个问题回答不佳）
- 对比同等级用户（百分位）
- 推荐重点复习资料（算法/系统设计）
- 估计真实面试通过概率

### 3.5 系统设计题库（P1）

**功能描述**：常见系统设计题目 + AI引导式解题。

**题目示例**：
- 设计短链接服务（TinyURL）
- 设计限流器（Rate Limiter）
- 设计分布式缓存（Redis-like）
- 设计秒杀系统
- 设计朋友圈（类似微信/Instagram）
- 设计搜索引擎
- 设计视频流媒体平台（类似 YouTube）

**解题引导**：
- **需求澄清**：AI 提出关键问题（用户规模？QPS？一致性要求？）
- **架构草图**：在线白板绘制架构图（集成 Excalidraw）
- **技术选型**：AI 建议数据库、缓存、队列等选型
- **深入设计**：数据模型、API设计、扩展性考虑
- **AI 评估**：对架构合理性、扩展性、容错性打分

**参考答案**：
- 文字版详细设计文档
- 架构图 + 数据流图
- 技术选型对比表
- 常见追问和回答技巧

### 3.6 代码审查工具（P1）

**功能描述**：提交代码后，AI 从多个维度进行审查，类似 Code Review。

**审查维度**：
- **功能正确性**：逻辑是否正确，边界条件是否考虑
- **安全性**：SQL 注入、XSS、CSRF、敏感信息泄露
- **性能**：时间复杂度、数据库 N+1 查询、缓存缺失
- **可读性**：命名、注释、代码结构
- **测试覆盖**：是否有单元测试，覆盖率
- **工程规范**：是否符合团队 Lint 规则

**输出报告**：
```
# 代码审查报告

## 🚨 严重问题（必须修复）
- [安全] 第45行：SQL拼接存在注入风险，建议使用参数化查询
- [性能] 第78行：循环内查询数据库，建议改为批量查询

## ⚠️ 需要改进
- [可读性] 变量名 `x` 不清晰，建议改为 `userId`
- [测试] 缺少边界条件测试用例

## ✅ 做得好的地方
- 错误处理完整
- 代码结构清晰

## 综合评分：76/100
```

### 3.7 对赌机制（涨薪/晋升）（P0）

**承诺**：完成学习要求，6 个月内未实现涨薪（跳槽或晋升）→ 全额退款。

**退款条件（需同时满足）**：

| 门槛项 | 标准 |
|---|---|
| 算法刷题 | 完成 ≥ 150 道题，通过率 ≥ 65% |
| AI编程实战 | 完成 ≥ 30 个任务，平均分 ≥ 70 |
| AI面试练习 | 完成 ≥ 20 轮模拟面试 |
| 系统设计 | 完成 ≥ 8 道系统设计题 |
| 代码审查 | 提交 ≥ 20 次代码，AI审查通过率 ≥ 80% |
| 活跃度 | 每周至少学习 3 次，无连续断更 ≥ 3 周 |
| 求职行为 | 投递简历 ≥ 30 家（平台推荐 or 截图证明）|
| 时限 | 购买后 270 天（9个月）内申请 |

**涨薪/晋升认定**：
- **跳槽涨薪**：新 Offer 薪资比当前薪资涨幅 ≥ 20%（提供 Offer 截图）
- **内部晋升**：晋升通知邮件 + 调薪记录
- **接受范围**：技术岗位（开发/测试/架构/算法等）

**退款流程**：
```
申请退款 → 系统核查完成度
→ 满足 → 提交求职证明（投递记录截图）
→ 提交收入证明（工资条/Offer对比）
→ 人工审核（3工作日）
→ 确认未达成涨薪/晋升 → 72h退款
```

**风险控制**：
- 虚假投递防范：随机抽查 3~5 份投递邮件真实性
- Offer 造假防范：交叉验证公司、岗位、薪资合理性
- 申请期限：9 个月（6 个月求职 + 3 个月宽限）
