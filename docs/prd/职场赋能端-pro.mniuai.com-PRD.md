## 一、背景与目标

### 1.1 背景

职场非技术人员（产品经理、运营、市场、HR、设计师等）在 AI 时代面临三大挑战：

1. **效率瓶颈**：写PRD、出报告、做会议纪要等重复性文档工作消耗大量时间
2. **数据分析门槛**：缺乏编程能力，无法高效处理和洞察 Excel 数据
3. **晋升竞争**：同岗位 AI 能力差异正在拉开薪资差距，不会用 AI 的人正在被淘汰

传统职场培训以课程为主，学完即忘，缺乏在工作流中的即时 AI 工具。ChatGPT 等通用工具对职场场景支持有限，缺乏模板库、行业知识和工作流整合。

萌牛AI 职场赋能端（pro.mniuai.com）定位为**职场人专属 AI 效率工具平台**，将 AI 能力直接嵌入文档写作、数据分析、会议纪要等核心工作场景，帮助职场人每周节省 10+ 小时，用能力提升推动涨薪晋升。

### 1.2 核心差异化

| 差异点 | 通用 AI 工具（ChatGPT/豆包）| 职场培训课程 | pro.mniuai.com |
|---|---|---|---|
| 场景化程度 | 通用，需要大量提示词工程 | 有场景，但教完即忘 | 内置职场场景模板，开箱即用 |
| 工作流整合 | 需要手动复制粘贴 | 无 | 与工作输入/输出直接对接 |
| 模板质量 | 无 | 有，但不可复用 | 职场专项模板库，持续迭代 |
| 效果保障 | 无 | 满意度调查 | 对赌：90天不提效全额退款 |
| 数据分析 | 需要专业知识 | 有课程但难落地 | 自然语言对话分析，零门槛 |
| 价格 | ¥20/月（ChatGPT）| ¥500~2000/期 | ¥99/月起 |

### 1.3 目标

1. 提效目标：使用核心工具 ≥ 20 次的用户，周均工作时间节省 ≥ 5 小时（自评）
2. 留存目标：30 日留存率 ≥ 55%，工具使用频次 ≥ 周均 8 次
3. 用户增长：3 个月内注册职场用户 ≥ 30,000 人
4. 付费转化：免费→付费转化率 ≥ 18%
5. 对赌退款率：≤ 5%（即提效成功率高）
6. NPS：≥ 55，推荐率 ≥ 40%

### 1.4 成功指标

| 指标 | 目标值 | 测量方式 |
|---|---|---|
| 注册职场用户数 | 3 月内 ≥ 30,000 | 注册数据 |
| 周活工具使用用户 | ≥ 10,000 | 工具调用埋点 |

## 三、核心功能设计

### 3.1 AI 工具广场（P0）

**功能描述**：所有 AI 工具的统一入口，卡片式导航，支持分类筛选和搜索。

**工具分类**：
- 写作类：AI文档写作 / AI商务邮件 / AI汇报材料
- 分析类：AI数据分析 / AI竞品分析
- 沟通类：AI会议纪要 / AI沟通话术
- 职业类：AI简历优化 / AI职业规划 / AI绩效总结
- 模板库：按岗位分类的职场文档模板

**推荐逻辑**：根据用户能力诊断结果和历史使用，推荐最适合的工具。

### 3.2 AI 文档写作（P0）

**功能描述**：针对 PRD、工作报告、项目方案、商务邮件等核心职场文档，提供 AI 辅助生成。

**支持文档类型**：
- **PRD（产品需求文档）**：输入产品名称/背景/目标/核心功能描述 → 生成完整 PRD 框架
- **工作报告**：输入时间段/工作内容/数据/问题 → 生成结构化工作报告
- **项目方案**：输入项目目标/背景/资源/时间线 → 生成完整项目方案文档
- **商务邮件**：输入收件人/目的/关键信息 → 生成专业邮件草稿

**AI 生成流程**：
```
用户填写表单（核心信息）
→ AI 生成初稿（SSE 流式输出）
→ 用户在线编辑完善
→ 一键复制或下载（Markdown/Word格式）
→ 用户评分（好评/差评+原因）
```

**模板系统**：
- 每种文档类型提供 3~5 个行业模板（互联网/金融/零售/教育）
- 用户可保存自定义模板供下次使用

**AI 生成质量要求**：
- 生成内容符合职场文档专业规范
- 不使用模糊表达（如"相关工作""一些改进"）
- 自动量化描述（如将"提升了效率"改为"效率提升约 30%"）
- 不泄露其他用户的文档内容

### 3.3 AI 数据分析（P0）

**功能描述**：上传 Excel/CSV 文件，通过自然语言提问，获得数据洞察和可视化图表。

**核心能力**：
- 文件解析：支持 .xlsx / .csv，最大 10MB，最多 10 万行
- 自然语言查询：如"本月各渠道 GMV 对比如何？"、"找出增长最快的品类"
- 图表生成：柱状图、折线图、饼图、散点图（SVG 渲染）
- 洞察摘要：自动提取 Top3 关键发现，用一段话总结
- 数据预览：展示前 20 行，字段类型自动识别

**交互流程**：
```
上传文件 → 字段预览 → 输入问题 → AI 分析 → 图表 + 文字洞察
→ 追问（基于上次分析上下文）→ 导出报告
```

**隐私保护**：用户数据加密存储，24 小时后自动删除，不用于模型训练。

### 3.4 AI 会议纪要（P0）

**功能描述**：将会议文字记录（手打/语音转写文字）整理为结构化会议纪要。

**输入方式**：
- 粘贴会议文字记录（支持杂乱格式）
- 填写会议基本信息：主题/日期/参与人/时长

**输出格式**：
```
# 会议纪要

## 基本信息
- 会议主题：XXX
- 时间：XXX
- 参与人：XXX

## 会议结论
1. XXX

## 关键决策
| 决策项 | 负责人 | 截止日期 |
|---|---|---|

## 待办事项（Action Items）
- [ ] [负责人] 任务描述（截止：日期）

## 下次会议
- 时间：XXX
- 议题：XXX
```

**AI 处理要求**：
- 自动识别并提取 Action Item（含责任人和截止日期）
- 不编造未在记录中出现的信息
- 对无法确认的信息标注 [待确认]

### 3.5 职业能力诊断（P0）

**功能描述**：20 道多选/单选题，评估用户在 5 个维度的 AI 应用能力，给出个性化工具推荐和学习建议。

**评估维度**：
1. 文档写作效率（4题）
2. 数据分析能力（4题）
3. 沟通汇报质量（4题）
4. 项目管理效率（4题）
5. AI 工具使用熟练度（4题）

**诊断结果**：
- 5 维度能力雷达图（0~100 分）
- 综合能力等级：AI萌新 / AI提效型 / AI达人 / AI高手
- 推荐优先使用的 3 个工具
- 针对薄弱项的 AI 使用建议

### 3.6 AI 简历优化（P1）

**功能描述**：用户粘贴简历内容 + 目标职位 JD，AI 给出针对性优化建议，提升 ATS 通过率和面试邀约率。

**优化维度**：
- **关键词匹配**：提取 JD 中的关键词，标注简历中缺失的高频词
- **成就量化**：将模糊描述改为带数据的成就陈述
- **结构优化**：调整模块顺序，突出与 JD 最匹配的经历
- **ATS 评分**：估算当前简历的 ATS 评分（0~100）
- **差距分析**：列出简历与 JD 要求的 Top5 匹配差距

**输出**：优化建议列表 + 修改后简历（可复制）+ ATS 评分对比

**隐私要求**：简历内容不存储超过 24 小时，不作为训练数据。

### 3.7 AI 汇报材料（P1）

**功能描述**：根据工作内容输入，AI 生成 PPT 大纲、周报、月报等汇报材料。

**支持类型**：
- **周报/日报**：输入本期工作内容 → 生成结构化周报（完成/进行中/待办）
- **月度述职**：输入月度工作内容+数据 → 生成述职 PPT 大纲
- **项目汇报**：输入项目进展+数据 → 生成管理层汇报材料

**质量要求**：
- 自动使用数字和百分比量化成果
- 不写废话（"在领导的指导下""认真贯彻落实"等空话自动过滤）
- 结构清晰，适合向上汇报

### 3.8 对赌提效协议（P0）

**承诺**：认真使用平台工具 90 天，若工作效率未提升 → 全额退款。

**退款条件（需同时满足）**：

| 门槛项 | 标准 |
|---|---|
| 工具使用次数 | 完成 ≥ 50 次 AI 工具调用（文档生成/数据分析/会议纪要等） |
| 完成学习任务 | 完成 ≥ 3 个职场 AI 技能提升任务 |
| 活跃天数 | 工具使用 ≥ 45 天（购买后 90 天内） |
| 申请时限 | 购买后 180 天（6 个月）内提交申请 |

**提效认定标准**：
- 主观自评：用户自评"工作效率明显提升"即视为提效成功（平台不核实）
- **退款适用场景**：用户认真使用后，主观感受效率未提升

**退款流程**：
```
提交申请 → 系统核查使用量（自动）
→ 满足门槛 → 填写无效反馈 → 人工审核（1工作日）
→ 确认申请合规 → 48h 退款
```

## 十、风险与待确认项

| 风险 | 影响 | 缓解措施 |
|---|---|---|
| AI 文档质量不达预期 | 用户满意度下降，对赌退款率升高 | 精心设计提示词模板，人工审核典型场景 |

| 职场用户付费意愿低 | 转化率不达标 | 强化免费 7 天体验，让用户先感受价值 |
