## 一、背景与定位

### 1.1 是什么

admin.mniuai.com（admin-app）是萌牛 AI 多端平台的**运营管理后台**，是面向内部运营团队的工具型产品，不对学员开放。

平台目前有 7 个用户侧产品：官网（mniuai.com）、程序员端（app）、大学生端（campus）、教师端（edu）、职场赋能端（pro）、少儿端（kids，规划中）。这些端的所有内容——课程、文章、题库、AI 配置——都需要通过 admin-app 统一创建、审核和发布。

### 1.2 解决什么问题

在没有 admin-app 之前，内容发布依赖开发人员直接操作数据库，存在以下问题：

- 内容发布无审批流程，易出错
- 多端内容无法区分归属，管理混乱
- RAG 知识库的向量化需要人工执行脚本
- 没有运营数据看板，无法监控各端日活和转化情况
- 没有角色权限控制，任何人可以操作生产数据

### 1.3 不是什么

admin-app **不是**学员端产品，不需要：

- 学习路径展示
- 视频播放器
- 对赌进度提交（只负责审核）
- 用户注册/付费购买流程
