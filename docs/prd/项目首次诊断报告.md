## 四、认证与权限

- **认证方式**: JWT (Redis 存储，非标准 JWT token)
  - Access Token: `acc_` 前缀，15分钟 TTL
  - Refresh Token: `ref_` 前缀，7天 TTL
- **安全框架**: Spring Security + 自定义 TokenAuthFilter
- **CORS**: 白名单 (localhost:3000/3001/5173)
- **权限**: 当前仅 USER 角色，无 ADMIN 角色实现
- **密码**: BCrypt 加密，最少8位
